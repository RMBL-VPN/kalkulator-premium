KALKULATOR PREMIUM — PROYEK ANDROID

Fitur:
- Tampilan modern warna ungu, hijau, dan gelap
- Tambah, kurang, kali, bagi
- Persen, ubah tanda positif/negatif, hapus satu angka, dan reset
- Bisa dipakai offline; tidak meminta izin internet
- Nama aplikasi: Kalkulator Premium

CARA MEMBUAT APK:
1. Ekstrak ZIP ini.
2. Buka Android Studio, pilih Open, lalu pilih folder KalkulatorPremium.
3. Tunggu Gradle Sync selesai. Jika diminta, pasang Android SDK Platform 35 dan Android Gradle Plugin yang sesuai.
4. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK debug biasanya ada di: app/build/outputs/apk/debug/app-debug.apk
6. Pindahkan APK ke HP Android lalu buka untuk memasang. Jika diminta, izinkan instalasi dari sumber tersebut.

Catatan: ZIP ini adalah source project Android Studio, bukan APK yang sudah dikompilasi. Lingkungan pembuatan ini tidak menyediakan Android SDK/Gradle untuk menghasilkan APK biner langsung.
